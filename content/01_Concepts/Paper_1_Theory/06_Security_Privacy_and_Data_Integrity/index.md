## What to know about this topic

> [!warning] The highest proportion of 9608 content in the vault
> **39 of the 110 Pack entries are 9608** — more than a third. Security changed relatively little between syllabuses, so the old questions remain live. Do not skip the `!warning` callouts here.

> [!success] The digital signature is a 5-mark question
> It is easy to under-describe. The full mark scheme runs **hash the message → produce a digest → encrypt the digest with the private key → send with the message → decrypt with the public key → re-hash the received message → compare the two digests**. Seven steps for five marks: `9618_s25_qp_11_sc_7.b`.

> [!note] Validation ≠ verification
> Validation checks data is **reasonable**; verification checks it has been **copied accurately**. Questions routinely offer the wrong one as a distractor, and an answer that confuses them loses every mark in that part.
