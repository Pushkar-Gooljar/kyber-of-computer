> [!question] 9608 | **The ACM/IEEE eight principles.** Name and describe three [6]

> [!question] SME | The Copyright, Designs and Patents Act [4]

>
>> [!success]- Answer — 6 points for 4 marks

## 7.1.4 Types of software licensing, and justifying a licence for a situation

> [!question] 9618 | Identify the most appropriate licence for a game and justify [4]
> A game is to be published under a software licence so that it can be sold to the public. Identify the most appropriate type of licence **and** justify your choice. *(1 mark licence + max 3 justification.)*
>
>> [!success]- Answer — 10 points for 4 marks
>> - **Commercial** software licence
>> - The user has to pay for the product, so the programmer can gain an **income**
>> - Enables the program to be **copyrighted**
>> - … so the user cannot **legally** edit the program // the programmer retains control over the product
>> - … and can take legal action against people who attempt to **illegally** copy or sell it on
>> - **Shareware** licence is also creditable:
>> - Enables the program to be copyrighted
>> - The user cannot legally edit the program, so the developer retains control
>> - The user can try the program for free and then pay for the full game, allowing the programmer to gain an income
>> - … so more people can experience it and are therefore more likely to buy it
>>
>> *Latest: `9618_s23_qp_13_sc_5.b`*

> [!question] 9618 | Describe each licence term in a table [4]
> Complete the table by describing each term: Copyright, Open Source (Initiative), Shareware, Software Licence.
>
>> [!success]- Answer — 4 rows for 4 marks
>> - **Copyright** — gives the holder the legal right of ownership of intellectual property
>> - **Open Source (Initiative)** — software can be freely copied, distributed or adapted
>> - **Shareware** — gives the user a trial period / limited functionality before a payment or sign-up may be required
>> - **Software Licence** — a (legal) agreement that defines the rights and terms of usage for the software
>>
>> *Latest: `9618_w25_qp_12_sc_2.a`*

> [!question] 9618 | Tick which licence(s) each statement describes [4]
> Tick one or more boxes in each row to identify the licence(s) each statement describes: Free Software Foundation, Open Source Initiative, Shareware, Commercial Software.
>
>> [!success]- Answer — 4 rows for 4 marks (1 mark per correct **column**)

>> - The user can redistribute the software → **FSF ✓ · OSI ✓ · Shareware ✓**
